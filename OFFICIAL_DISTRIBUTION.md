Explicit written confirmation from `Missher12` is required before re-uploading or mirroring an official plugin archive, checksum, or Release asset while presenting it as official, canonical, unmodified, approved, or endorsed by Missher; before republishing it through a plugin market, download site, update channel, or bundle under Missher identity; or before using Missher branding in a way that could make an unofficial build appear official.

Request confirmation in the canonical repository and address it to `Missher12`. Only explicit written approval counts. Silence, a checksum match, or an unchanged archive is not approval.

Source mirrors and forks remain allowed under [LICENSE](LICENSE) when required notices are preserved and the result is prominently marked unofficial. Independently built derivatives must use a non-confusing identity and must not imply Missher approval. Linking to the canonical Release without copying or relabelling it needs no confirmation.
